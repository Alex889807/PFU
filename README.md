# Ejercicio 21: Sala de informática

## Descripción
Programa en Python que administra los equipos de una sala informática mediante:

- Una lista enlazada para guardar y mostrar los equipos.
- Una pila para demostrar LIFO: último en entrar, primero en salir.
- Una cola para demostrar FIFO: primero en entrar, primero en salir.
- Una búsqueda por código.

## Datos de prueba
- PC01: Equipo 1
- PC02: Equipo 2
- PC03: Equipo 3

## Cómo ejecutar
Tener Python 3 instalado y ejecutar:

```bash
python main.py
```

## Reto individual
La función buscar(codigo_buscado) recorre la lista desde el primer nodo.
Si encuentra el código, devuelve el nodo correspondiente.
Si no lo encuentra, devuelve None.
